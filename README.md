# 落雁镇 · 蜜月

一个约 20 分钟的网页 ARG 恐怖解谜原型。全程只有一块手机屏幕：你在落雁镇度蜜月，靠论坛、小程序、监控后台、云盘和一段录音，查清一桩三十九年前的阴婚。

- **类型**：民俗微恐 / 网页解密 / 三结局
- **形式**：参考《邺山彼处》的网页 ARG——线索藏在伪网站、删帖快照、全景图、监控时间轴里
- **体量**：8 个节点，5 个谜题，3 个结局
- **依赖**：无。纯静态 HTML/CSS/JS，双击即玩
- **声音**：没有音频文件，雨声、水声、祠堂低频、敲门、磁带、铃声全部由 WebAudio 实时合成

---

## 怎么打开

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 或者右键 → 打开方式 → 浏览器。

进度自动存在浏览器本地（`localStorage`）。想重来：游戏内「设置 → 重新开始」。

> 建议戴耳机、关灯。敲门声和低频是浏览器实时合成的，没有音频文件。

## 操作

| 操作 | 方式 |
|---|---|
| 打开 App | 点桌面图标 |
| 浏览网页 | 点页面里的链接，或在地址栏输入关键词搜索 |
| 输密码 | 点输入框，输入后点按钮 |
| 拖时间轴 / 全景 | 拖动滑块，全景页也可以直接按住画面拖动 |
| 返回 | 左上角 `‹` |
| 回主屏幕 | 左上角 `‹`，或点手机底部那条横杠（全局有效） |

**核心玩法是搜索**。线索里出现一个词（比如「库房」「镇志」「云盘」），就去浏览器地址栏搜它。搜不到的词会给你一个被屏蔽的页面。

## 微信与通知

微信做成了接近原生微信的结构：

- **四个 tab**：微信 / 通讯录 / 发现 / 我
- **聊天列表**：头像、昵称、最后一条消息、时间、未读红点
- **聊天窗口**：绿白气泡带小尾巴、时间分隔、底部「按住 说话」输入栏
- **朋友圈**：知遥 2022-12-03 那条「奶奶走了」——这是云相册密码的年份线索
- **通讯录**：知遥、何婶、赵鹤年、周叔，以及你后来添加的夜航船
- **朋友要自己加**：夜航船不会天生出现在你的微信里。读完 203 那个删帖快照，签名里有他的微信号 `yhc_1987`；去微信「通讯录 → 添加朋友」搜这个号，才能加他。
- **见过面才会加你**：周叔在渡口接你们时就见过，当晚自动加上；赵鹤年是第二天早上堵在民宿门口，当面加你。

新消息到达时，屏幕顶部会滑下一条**手机横幅通知**（应用图标、发送人、消息预览、时间），3.8 秒自动收起，**点一下直接进入对应聊天**。多条消息会排队逐条显示。正在和某人聊天时不会弹他的通知。

聊天里可以回复。底部会出现 2–3 条**情境回复**，选一条就发出去，对方会接话；有些回复会推进线索。已经用过的回复不会重复出现。特殊时刻（比如知遥被带走之后），消息发出去但不会有人回。

## 目标与手记

游戏里有两个东西专门防止“不知道下一步干什么”：

- **首页目标卡**：永远显示当前章节、这一章要做什么、以及一个「去办」按钮，点了直接跳到该去的地方。
- **手记 App**：自动记录你看过的**线索**（房卡密码、生辰、订单号、忌日、名字、尸骨位置……）和**地点**（去过的论坛、民俗馆、库房、云盘……），点地点可以一键回去。

找不到路的时候先翻手记。它不会告诉你答案，但会告诉你手里已经有什么。

| 结局 | 触发 | 一句话 |
|---|---|---|
| 留镇 | 破坏仪式物件 | 你烧掉了唯一能注销契约的东西 |

| 破局 | 证据 ≥ 4 且开直播 | 鬼要的从来不是命，是有人肯把她的名字念对 |

真结局需要 **5 件证据里的 4 件，且必须知道她的名字**。少一件，祠堂里的镇民只会当你在说疯话。

## 目录

```
落雁镇/
├─ index.html      手机外壳与启动屏
├─ style.css       全部样式与纹理合成
├─ data.js         剧情文本、伪网站页面、结局
├─ audio.js        程序化音频（环境层 + 音效）
├─ game.js         状态机、导航、谜题、结局演出
├─ assets/         Pillow 生成：纸纹、雨幕、木纹、老照片、古镇远景
└─ README.md
_qa/
├─ smoke.js        渲染冒烟测试（所有页面 + 三个结局）
├─ flow.js         完整通关测试
├─ check.js        静态检查（页面跳转与交互是否都有实现）
└─ gen_assets.py   重新生成 assets/ 里的纹理
```

`assets/` 里的图片不是实拍或 AI 生成，是用 Pillow 程序化画的：纸纤维、雨丝、木纹、受潮的老照片、雾里的古镇。想换风格，改 `gen_assets.py` 重跑即可。

运行测试（需要 Node）：

```
node _qa/smoke.js
node _qa/flow.js
```

两个脚本用最小 DOM 桩在 Node 里跑完整逻辑，不依赖浏览器。

## 已知限制

- **纹理是程序化生成的**：纸、雨、木、老照片都由 Pillow 画出来，近看仍是抽象质感，不是实拍或 AI 图。
- **没有配音**：环境音和音效是 WebAudio 合成的，没有人声。嫁歌只存在于文字里。
- **移动端未专门适配**：手机浏览器能玩，但未做安全区、横屏、震动反馈。
- **存档是本地单机**：清浏览器数据会丢进度。
- **结局演出是逐段文字 + 音效 + 闪白**，没有做到大纲里写的镜头级运镜。

## 声音

- 首次点击「按此开始」后才会启动音频（浏览器要求手势）。
- 场景切换会交叉淡入：雨 → 室内 → 祠堂低频 → 监控底噪 → 水边。
- 想静音：桌面「设置 → 声音」，或直接调系统音量。静音状态会记住。
